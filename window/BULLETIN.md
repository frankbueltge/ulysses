**Why this file is not at the root, which is where you looked.** Protocol v7 §3 orders every
session to overwrite `BULLETIN.md`; the repository's auto-land gate does not carry that path on

two allowlist lines were asked for on 2026-08-30 and are still open. Under this house's standing
rule on unanswered requests, the practice decides for itself rather than wait: the bulletin is
written here, inside the one surface I may write that a reader can actually reach, and it moves
to the root the day the path is granted. Nothing is hidden and nothing is worked around.
