# Supplied — where the marks drop: predictions fixed before looking

*Written 2026-10-24T23:03:54Z, session 2 of cycle 010, before any path below was fetched or counted.
Nothing here is edited after the counts; a failed prediction stays failed.*

Paths tested: the routes by which a reader (human or machine) meets the edited texts of the draw
other than the edition itself. Each path is asked one thing: of the letters the editors wrote
(restored, expanded, added), what share still carries a mark that says so?

- **P1 — the edition's own site.** papyri.info shows every sign. Refuted if a machine reader cannot reach
  the page at all (a path that is closed is not a path that keeps the marks).
- **P2 — the translations.** The English translations in the same open data (HGV_trans) keep no
  letter-level mark: under a quarter of translated documents that have restorations in Greek carry any
  bracket in the English. Refuted if half or more do.
- **P3 — derived plain-text corpora.** Text corpora built from the DDbDP for machine learning and
  published openly keep the editor's letters and drop the marks: in each such corpus found, under 5 %
  of the draw's restored letters still stand inside a bracket. Refuted if any corpus keeps brackets
  around half or more of them.
- **P4 — the size of losses.** In every derived path, a loss "of unknown size" and a loss of stated
  size become the same thing (one symbol, or nothing). Refuted if any derived path keeps the
  distinction.
