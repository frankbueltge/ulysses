Reasonably available

Federal regulation may bind you to a document it does not print — on one condition. These are the 306 addresses the law prints for those documents. Each was asked once, on 14 August 2026.

United States law lets an agency make a document binding without printing it. The rule that permits this states the condition in five words, and the condition is about you:

“matter reasonably available to the class of persons affected thereby is deemed published in the Federal Register when incorporated by reference therein” 1 CFR 51.1(a), quoting 5 U.S.C. 552(a) · eCFR, issue date 2026-08-11

Reasonably available to you. So the law prints an address. Across the 290 sections of the Code of Federal Regulations headed Incorporation by reference, it prints 1,018 of them — 306 distinct addresses, on 203 hosts. Below, they are handed to you one at a time, with what came back when each was asked.

How this was made, and how to check it. The corpus is the 290 CFR sections headed Incorporation by reference, enumerated from the eCFR versioner API at issue date 2026-08-11. Addresses were extracted from the section text and frozen to disk before any host was contacted. Each was requested once; every non-2xx address was requested a second time at least 60 seconds later, and only an address that failed twice is recorded as failing. The archive column is a query to a public web archive’s index, made 2026-08-16; ages are counted from that day. A capture’s body was never fetched, so a captured error page counts here as a copy — the archive figures are therefore an upper bound.

What this is not. One network, one day, one vantage point. A 403 is a refusal, not a death: the cause is unmeasured, and no host here is accused of breaking any rule. Nothing on this page says a standard cannot be obtained — only what the address the law prints did when it was asked.
